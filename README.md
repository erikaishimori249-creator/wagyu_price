# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？

#### リモートリポジトリ
 - ネットワーク上に配置して複数人で共有するためのもの

#### ローカルリポジトリ
 - 開発者が使うために自分のPC上に配置するためのもの


## プッシュとマージの違いは何でしょうか？

#### プッシュ
 - ローカルリポジトリで変更した内容をリモートに反映させること

#### マージ
 - 別のブランチの作業内容をブランチに取り込むこと

## コミットとプッシュの違い

- コミットはローカルリポジトリに作業履歴を記録することで、プッシュはリモートリポジトリに送信すること

## コミットのメッセージはどのように書いてあげるのが最適でしょうか？

- 変更内容を分かりやすく書く

## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？

- コードレビューの有無

## コンフリクトを起こしてしまった場合、どう対処すべきですか？
1. 先にマージされた変更内容を取り込む
2. 後にマージしようとしている変更内容を取り込む
3. どちらの変更内容も取り込む
